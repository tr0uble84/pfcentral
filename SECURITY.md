# Security policy

PFCentral manages firewalls, so security reports matter a lot.

**Please don't open a public issue for a vulnerability.** Report it privately through GitHub:
**Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it, and the
version (see `VERSION`).

You'll get an answer as soon as possible. Fixes are released as a new version; please give us time to release a fix
before you share details publicly.

Only the latest release is supported.
